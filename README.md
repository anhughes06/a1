# CMPUT 301 Fall 2026 - Assignment 1
## App Description
Develop an Android app called [your CCID]-RapidRecall. The app is a memory-based game in which players must recall and re-enter a sequence of numbers that are briefly displayed one digit at a time on the screen.

Before starting a round, players can choose the length of the number sequence they want to practice. During gameplay, each digit in the sequence is shown briefly, then the user must accurately input the entire sequence.

After each round, players immediately receive feedback indicating whether their answer was correct or incorrect, along with a comparison of the correct sequence and their input.

The app also includes a statistics feature that tracks player performance within a session. This includes per-round results plus aggregated statistics such as total rounds played, number of correct attempts, and accuracy percentage.

> [!NOTE]  
> Data persistence is optional. "Within a session" refers to the period while the app is running. Statistics only need to be maintained until the app is closed or terminated. Storing data in a database, file, or other persistent storage is not required.
